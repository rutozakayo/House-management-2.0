Move your data from the old app

The old version stored records as rentalManagerV1. This page turns that into a backup file that the new app can restore. Nothing is uploaded anywhere.

Option 1 — this browser still has the old data

Checking this browser…
Open the new app

This only works if this page is opened from the same address as the old app (same folder on the phone, or same web address). Otherwise use option 2.

Option 2 — paste the data from the old app

  1. Open the old app in a browser.
  2. Open the developer console (Chrome: menu ⋮ → More tools → Developer tools → Console).
  3. Run copy(localStorage.getItem('rentalManagerV1')) — this copies the data.
  4. Paste it in the box below and press Convert.

Then, in the new app

Open Settings → Restore backup and choose the file you just downloaded. It replaces whatever is on the device, so do it before you start entering new records.
